The project's own memory. What is written here is handed to every agent that starts in this project, before it reads a single file. See Memory for the concept; this page is the surface.

Three tabs

Knowledge
Facts about this project, grouped into four kinds. These are briefed.
Notes
Your working memory for this project. Pinned, reordered, deleted — and never composed into a brief.
History
This project's own story: what happened here, rather than the global Activity feed.

The four kinds, and how to choose

KindAsk yourselfExample
What this project is What would you say in the first thirty seconds to someone new? The billing service: invoices, credit notes, and the reconciliation job at 02:00 UTC.
How work is done here What convention would an agent violate without knowing? An invoice is immutable once issued. Corrections are credit notes, never edits.
Things that will bite you What has already cost somebody an hour? The dev server listens on 4173, not 3000 — 3000 is held by something else here.
What words mean here Which of your words mean something specific? A tenant is a billing account, not a user.

Stated and derived are separate

What you wrote carries You wrote this. What an agent wrote carries An agent recorded this, in amber. And facts the product derived — the branch, the languages, what changed recently — live on their own tab, are recomputed on every read, and are never stored.

That separation makes the confidence rule structural. You cannot mistake a computed fact for a stated one, because they are not in the same list.

Retiring

Knowledge that stops being true is retired, not deleted: it stops being briefed and the record stays. A fact that governed this project for six months is part of its story even after it stops being true — and a deleted one leaves the next person wondering why the code looks like that.

Promoting a note

When a note turns out to be a fact the next agent should know, one action promotes it into knowledge — and it leaves the notes list, because it is now a different kind of thing. There is no state where the same sentence is both.

What an agent writes here

At the end of a successful unattended run, once, the agent is asked what would still matter next time. Not a summary of what it did. It is forbidden from touching anything while it answers, and it is given a named escape hatch that is expected to fire most of the time.

A manually completed mission is never asked — typing a question into a terminal you are watching is a different conversation to interrupt.

The real one

An agent finished a trivial unattended mission and answered: GOTCHA: The dev server runs on port 4173, not the conventional 3000, because port 3000 on this machine is already held by an unrelated port scanner — anyone expecting localhost:3000 will find nothing there. That appeared in the Gotcha tab under An agent recorded this, in amber, with the briefed-size counter moving and Activity recording it right after the mission's own completion.

How it gets to the agent

Out of band. The brief is written into J.A.R.V.I.S.'s own data directory and passed to Claude Code with --append-system-prompt-file. Nothing is written into your repository — a context file in a working tree would appear in Review, in your git status, and eventually in a commit.

Codex has no equivalent flag on 0.147.0, so it is honestly reported as OpeningMessage rather than being handed a file it would never read. See Providers and capabilities.
