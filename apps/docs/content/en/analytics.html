When you have been working, what it cost, and how much of it happened while nobody was watching — folded from the same session logs everything else reads, plus the provider's own transcripts.

The calendar

One cell per day, graded by how much passed through it. Clicking a day scopes the whole screen to it; clicking it again, or the chip at the top, lets go. The calendar itself never scopes — it is the picture and the control at once, and a control that erases itself when used leaves no way back.

A day with no history is not a day off

Cells from before the first turn anyone recorded are drawn as an empty outline, not as a quiet day. On a 90-day range over a fortnight of data, the obvious version invents seventy-odd idle days that never happened. This is the same rule as Official and Observed, applied to a shape instead of a number.

The ramp is amber at four strengths, on a square-root scale. A linear one would let a single enormous day flatten a fortnight of real work into the palest band.

A streak, without the nagging

There is no target, no goal, and nothing that tells you off for a gap. One turn is enough for a day to count — any rule with a number in it would be this product deciding how much work counts as work. The magnitude is not lost; it is what the calendar's shading carries. A quiet day is a day off, and the screen says so.

Human leverage

Human time
The minutes you actually spent typing in a session. Measured from real interaction, not inferred from how long a window was open.
Agent runtime
How long sessions were active.

The ratio between them is the number this product exists to move. It is stated plainly rather than turned into a score, because a score would need a scale nobody agreed on.

It says how far back it can see

Tokens reach as far back as the provider's transcripts do. Attention and session lifetimes only reach back to when J.A.R.V.I.S. was first watching — nothing recorded keystrokes before that. So the row carries the date it is measured from. A ratio computed over thirty days of tokens and two days of attention would be the most flattering figure on the screen and the least true.

Where the history comes from

Analytics used to count only what J.A.R.V.I.S. itself watched happen, which on a new install is nothing. The provider keeps its own transcripts, and they hold the same work — so on first launch a background pass reads them and recovers the token history that was always on disk.

It runs once, resumably, off the startup path, and it is safe to repeat: every turn carries the provider's own identifier, and a transcript belonging to a session this product ran is never read at all, because those turns are already recorded. Nothing is invented — no sessions, no projects. A recovered turn carries the folder it happened in as a plain label, which is why a project you have never opened here can still appear by name.

Time of day, project, model

Tokens by hour of the local day, then by project, model and provider. Every one of these is Official — the provider's own usage object. Nothing here is estimated; a figure that cannot be sourced from a provider statement is not shown as though it could.

One hue, on purpose

Bars use a single colour because each row is already named beside it: the bar carries magnitude, the label carries identity. Colouring by rank would double-encode length as hue — the same information twice, in a channel that then cannot be used for anything else.

Ranges

7, 30 and 90 days. Long enough that a slow week does not read as a collapse, short enough that what you changed last month is still visible. Days are bucketed in your own time zone, so an evening's work lands on the evening you did it.
