The home screen. It answers one question — what needs me? — and then gets out of the way.

Four sections, in the order that matters

Needs attention
Missions blocked or waiting, agents that stopped to ask something, guardrail decisions nobody has answered. First, because it is the only section that is urgent.
Working now
Agents actually running, and the missions they are running against. This is the reassurance section: it tells you that something is happening without you having to open anything.
Recently completed
What finished, with the mission it finished. Recent enough to still be interesting.
Active projects
Where you have been working, with the branch each one is on. The way back in.

An empty section vanishes

The rule this screen is built on

A section with nothing in it is not rendered at all — not as a heading with an empty state under it, not as a greyed-out placeholder. It is gone.

The reason is that this screen's whole job is to make the important thing obvious. A Needs attention heading followed by Nothing here teaches you to skip past that heading, so the day something genuinely is waiting, your eye has already learned not to stop there. Four empty sections is a screen that says nothing loudly.

When everything is empty, the screen says so once — Nothing is running — and offers the one useful action: open a project.

Reading a row

A mission row carries its status, its project, and the specific thing that is unresolved — 1 unverified rather than a generic warning. Clicking it goes to the mission, not to a list containing the mission.

An agent row goes to the session it names. If that project is already open, it still works: re-opening the same project is not a remount, and a notification that pointed at an already-open project used to do nothing at all until that was fixed.

A row for an archived project

Clicking a row whose project has been archived used to silently do nothing — a fall-through that had been there since Global Search was built. It now says what happened rather than swallowing the click.

The status bar underneath

Two things live down there permanently, because they are the answers to questions you ask while doing something else:

  • Environment state — whether the tools this product needs were found.
  • Quota chips — each provider's remaining allowance and when it resets. See Accounts and quota.

The rail

Six destinations and Settings, and it does not grow. Mission Control, Projects, Missions, Activity, History, Analytics — then Settings, pinned to the bottom.

Everything that is scoped to a project lives inside the project instead: Files, the editor, Review, Preview, Worktrees, Brain and that project's own Settings. A rail that grows every time a feature ships is a rail nobody can scan.
