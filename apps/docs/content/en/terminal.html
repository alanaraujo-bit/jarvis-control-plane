This is the hero surface. Every agent runs here, and it is a real pseudo-terminal — the same CLI, the same keys, the same TUI it draws for you outside this product.

Tabs, and what a tab is

The + beside the tab strip offers a plain Shell and every agent the environment scan found. A provider that is not on your PATH is not offered.

Each tab is one session, and a session is one append-only event log. Closing the tab does not necessarily kill the process, and the log outlives both — which is why a session you closed months ago can be reopened from History.

Processes cannot outlive the app

Agent processes are contained in Windows job objects. Quitting J.A.R.V.I.S. takes its agents with it, so you never end up with an orphaned CLI holding a file lock or spending tokens where nothing is reading the output.

Splitting

Up to four terminals at once, in three layouts: side by side, stacked, and grid.

Splitting changes CSS boxes, never the tree

A terminal is never re-parented when you split. A remounted terminal has lost its scrollback, and losing an agent's scrollback because you wanted to see two of them is not a trade anyone would accept. Each pane's box changes; no terminal moves.

Presets rather than a drag-resizable tree, and four rather than unlimited. Both are deliberate: a fifth pane at this window size is narrower than the prompt most agent CLIs draw, so it would be an option that produces an unusable terminal.

Closing a pane closes the pane. The session keeps running — the label on the button says so.

Searching the scrollback

CtrlF opens a panel over the terminal rather than a dialog over the app: you are searching this terminal, so the search belongs to it. Match-case, a live counter, previous and next.

An overview ruler appears down the side while you are searching and is absent the rest of the time, so there is no empty gutter sitting there permanently. Matches are drawn in blue, never amber — amber means agent work in this product, and a search hit is not agent work.

The bug that made this hard

CtrlF fell through to WebView2's own find-in-page whenever the terminal did not literally hold DOM focus. It is now resolved in the capture phase, and Shift is excluded outright so CtrlShiftF can stay Global Search. It also lowercases the key, because event.key is "F" whenever CapsLock is on.

Pasting an image

CtrlV with an image on the clipboard writes it into the session's own directory — never your repository — and types the quoted path at the prompt, unsubmitted. A chip says an image is attached; hovering it shows the actual picture rather than a filename.

Writing into the session directory rather than the working tree is the same rule the Brain brief follows: nothing this product generates should appear in your git status.

The webview cannot see a pasted image at all

WebView2 raises no paste event for clipboard image data — only for text. The Rust core reads the clipboard directly. This was found by instrumenting the running app after two DOM-shaped attempts produced nothing at all, which is a good reminder that a feature that "should work" and produces no event is not a bug in your handler.

Copying

CtrlC copies when there is a selection, and sends ^C when there is not — the behaviour every terminal user already has in their fingers. If the clipboard write is denied by the host, the selection is kept so you can retry rather than being cleared.

Preferences apply in place

Changing the terminal's type size or scrollback in Settings → Terminal never rebuilds the terminal. A rebuild kills the process and throws away the scrollback. Changing the size also refits and tells the PTY its new dimensions, or the shell keeps wrapping at the old width.

Verified in a real build

The type size was changed while a shell was running: it grew, kept its scrollback, and ran the next command. The preference survived a restart, and Reset returned it to 13 with the label going back to Default.

Dictating into it

The microphone button beside the tabs starts voice dictation. It transcribes locally, primes itself with your project's own vocabulary, and types into the prompt without submitting — the same rule the image paste follows. Pressing Enter stays yours.
