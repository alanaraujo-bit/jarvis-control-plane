The short version

Claude Code, Codex and whatever comes after them are extraordinary at writing code and hopeless at everything around it. They have no memory of your project, no idea which of your four subscriptions still has allowance, no way to prove they finished what they said they finished, and no record of what happened after you closed the window.

J.A.R.V.I.S. is the layer above them. They become execution providers inside it. Projects, missions, agents, sessions, code and verification live in one place, so the distance between an intention and working software is as short as it can be.

What it actually does

You open a folder. You start an agent in a real terminal inside it — not a chat window pretending to be one. From that moment the product is doing four things at once that no agent CLI does for itself:

It keeps the record Every byte the process wrote, every structured turn, every token count, every file touched — in one append-only log per session, on your disk. It checks the work A mission is finished when real commands pass and real files exist — and it is unfinished the moment they stop. It holds the dangerous things A force push, an rm -rf, a production deploy — stopped before they run, for a decision that is yours. It watches the meter Which of your subscriptions is holding you up, when its window resets, and where new work should start instead.

The one idea to read first

Almost every design decision in this product follows from a single one, and it is worth five minutes before anything else:

A session is not a terminal widget plus a chat widget. It is one append-only, ordered event log. Everything else — the terminal, the conversation, the usage numbers, the activity feed, the evidence on a mission — is a projection of that log.

This is why you can flip a running agent between Terminal and Conversation without touching the process. It is why a session you closed last week is still searchable by what was said inside it. It is why token counts are the provider's own numbers rather than an estimate. And it is why there is no second store that can disagree with the first one.

Local-first, and what that means precisely

Your code, your Git history, your terminals, your provider credentials and every session you have ever run stay on your machine. There is no account to create and nothing is uploaded to use the product.

Two things can leave, and both are switches you turn on:

  • The phone relay. A summary of what needs a person — never file contents, terminal output or conversation text. Off unless you pair a device. See Local-first.
  • The agent itself. Claude Code and Codex talk to their own providers, on their own terms, with your own credentials. J.A.R.V.I.S. launches them and reads what they write to disk; it never proxies their traffic.

What it is not

Not an editor with a chat panel
Monaco is here, and it is deliberately small — no language services, loaded on demand (why). The product is not competing for the hours you spend typing code yourself.
Not another agent
Nothing here writes code. It runs the agents you already pay for and tells you the truth about what they did.
Not a wrapper around one vendor
Two providers ship today and they genuinely differ. Those differences are data the interface reads, so the interface stays honest about which one can do what.
Not finished
Several things are deliberately absent rather than stubbed, and one page says which and why. There is also a page of open blockers, including the unsigned installer.
