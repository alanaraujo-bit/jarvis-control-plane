What happened, in order, filterable. Not a debug log — a record of the moments worth knowing.

Recorded at moments, not at events

Why this is not a firehose

Every byte an agent writes is already in the session log. Activity does not repeat it. It records the moments a person would want to reconstruct later: a session started, a mission changed state, a guardrail decided something, an agent wrote to the Brain, an account switched, a run stopped and why.

A feed that records everything is a feed nobody reads, and then the one event that mattered is buried under nine hundred that did not.

Filtering

By project, by kind, and by time. The filters exist because the two questions people actually ask are different shapes: what happened in this project? and what happened around 14:30?

Everything here is translated

Activity entries are sentences J.A.R.V.I.S. wrote, so they carry a translation code and their specifics as arguments — never English text stored in your database and shown to a Portuguese reader.

The exception is the same one everywhere else: an agent's own words, and a tool's own output, are not translated. If an entry quotes something the agent said, that quote is what it said.

The project's own history

Activity is global. A project's Brain → History tab is the same idea scoped to one project — its own story, without the noise of everything else you were doing that week. Two surfaces because they answer two different questions, not because one is a filtered view somebody forgot to make.

What it is good for

Reconstructing an unattended run
Every turn boundary, every verification, and the reason it stopped — in sequence. See Run a mission unattended.
Finding out why a completion was revoked
The re-verification that failed is here, with the criterion it failed on.
Auditing what a guardrail did
Every decision, with the operation it classified and the answer it gave.
Understanding an account switch
When work moved, from which account to which, and what triggered it.
Global Search Searches activity too, alongside knowledge, notes, missions and what was said in any conversation. Analytics The same events, counted rather than listed.
