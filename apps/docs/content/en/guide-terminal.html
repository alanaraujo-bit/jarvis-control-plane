The terminal is where the work happens, so it is worth ten minutes of learning. Five things that change how the product feels.

Four agents at once

Split into up to four panes, in three layouts: side by side, stacked, or grid. The natural setup is one agent per concern — one implementing, one running tests, one you are typing in yourself.

Splitting cannot cost you a scrollback

A terminal is never re-parented. Only its CSS box changes. A remounted terminal has lost its scrollback, and losing an agent's history because you wanted to see two of them at once is not a trade anyone would take.

Closing a pane closes the pane — the session keeps running, and the button says so. Four is the ceiling because a fifth pane at a normal window size is narrower than the prompt most agent CLIs draw, so it would be an option that produces something unusable.

Search that does not fight the browser

CtrlF opens a panel over the terminal, with match-case, a live counter, and an overview ruler that appears only while you are searching.

If you have used a terminal inside another web-based app, you have probably had Ctrl+F open the browser's find bar instead. That happened here too, whenever the terminal did not literally hold DOM focus. It is resolved in the capture phase now, with Shift excluded so that CtrlShiftF stays Global Search.

An image straight into the prompt

Copy a screenshot, click into a terminal, press CtrlV. The image is written into the session's own directory and the quoted path is typed at the prompt, unsubmitted. A chip says an image is attached, and hovering it shows the actual picture.

Nothing lands in your repository, so nothing appears in your git status or in Review. That is the same rule the Brain brief follows.

Your prompt library, one shortcut away

CtrlShiftN opens the Notebook over whatever you are doing, and one button sends a note into the terminal you were on — arriving in the prompt, unsent, so you can still edit it.

Sending is refused when the receiving program has not enabled bracketed paste, because a plain shell would read a multi-paragraph prompt as twenty commands rather than one prompt.

Dictate instead of typing

The microphone button beside the tabs. Transcribed locally, primed with your project's own file names and branch, and typed into the prompt without submitting. Useful exactly when a prompt is three paragraphs of context you would rather say than type.

Two more things worth knowing

Type size applies without a restart
Change it in Settings → Terminal and a running shell grows, keeps its scrollback, and runs the next command. It also refits and tells the PTY, or the shell would keep wrapping at the old width.
Ctrl+K no longer reaches your shell
It is the command palette, resolved globally before any widget sees it. So readline's kill-to-end-of-line is gone. This is the same trade VS Code and Cursor make, and it is stated rather than left for you to discover.

Nothing outlives the app

Agent processes are contained in Windows job objects. Quitting takes its agents with it, so you never end up with an orphaned CLI holding a file lock or spending tokens where nothing is reading the output.
