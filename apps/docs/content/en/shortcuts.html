The whole list is short. Read the last section before you get surprised by it.

Global — resolved before any widget sees them

KeysDoes
CtrlK Command palette — every destination, every settings section by name, every action. Subsequence-ranked.
CtrlShiftF Global Search — knowledge, notes, missions, activity, and what was said in any conversation, across every project.
CtrlShiftN The Notebook — your prompt library, over whatever you are doing.
Why all three are handled in the capture phase

The terminal and Monaco both claim keys before a normal listener ever sees them. A shortcut the interface advertises has to be resolved before any widget gets an opinion about it, or the titlebar goes on promising something that silently stopped working.

Each of them also lowercases the key, because event.key is "K" whenever Shift or CapsLock is down — a plain comparison silently stops working for anyone with CapsLock on.

In a terminal

KeysDoes
CtrlF Search the scrollback. A panel over the terminal, with match-case, a live counter, and an overview ruler that appears only while searching.
CtrlC Copies when there is a selection. Sends ^C when there is not.
CtrlV Pastes text normally. With an image on the clipboard, writes it into the session's own directory and types the quoted path, unsubmitted.
Esc Closes the scrollback search panel.

In the editor

KeysDoes
CtrlS Save. Refused if the file on disk is no longer the one that was opened — nothing is written and your buffer is untouched. Saving again overwrites deliberately.

In a text area

KeysDoes
CtrlEnter Submits, in the Brain and in Review's commit box. Enter alone inserts a newline, because these are places where a paragraph is a normal thing to write.

In an overlay

KeysDoes
↑ ↓Move through results.
EnterOpen the selected one.
EscClose.

The one the product takes away from you

CtrlK no longer reaches your shell

In a shell, Ctrl+K is readline's kill-to-end-of-line. Here it is the command palette, resolved globally, so your shell never sees it.

This is the same trade VS Code and Cursor make. It exists because Monaco treats Ctrl+K as a chord prefix and called stopPropagation on it — so the palette silently stopped opening whenever the editor had focus, while the titlebar went on advertising the shortcut.

It is reversible. One file decides it. Letting the terminal keep the key means either dropping to the bubble phase — and losing the palette while the editor has focus — or exempting the terminal's own subtree from the capture handler. The second is the one worth building if you want the key back.
