The words this product uses, in the sense this product uses them. Several of these are ordinary words with a specific meaning here, and mistaking the general sense for the specific one is how the rest of the documentation stops making sense.

Account
A provider configuration directory — CLAUDE_CONFIG_DIR or CODEX_HOME — and whatever credentials live in it. Not a J.A.R.V.I.S. account; there is no such thing. More
Agent
A running session of a provider CLI. Not a persona, not a configuration — a process.
Area
One of the seven tabs inside a project: Sessions, Files, Review, Preview, Worktrees, Brain, Settings. Distinct from a destination.
Autonomy
How much an agent decides on its own — Guided, Autonomous or Unattended. The broad question. More
Brain
A project's own memory. The knowledge in it is briefed to every agent that starts there; the notes in it are not. More
Brief
The composed text handed to an agent before it starts, out of band, containing only knowledge. Never written into your repository.
Criterion
One acceptance condition on a mission, with a verification attached: a command to run, a file to check, or a judgement only a person can make.
Destination
One of the six places on the rail, plus Settings. Distinct from an area, which lives inside a project.
Driven
A session the autopilot is steering rather than a person. A driven session tells the guardrail it is driven, which is why an ask rule refuses instead of prompting.
Evidence
What a verification actually produced — an exit code, a command's real output, a file's presence, or a person's confirmation. Stored, not summarised into a tick.
Frame
One entry in a session's log: a length, a sequence number, a timestamp, a one-byte kind and a payload. More
Guardrail
A rule about a class of sensitive operation, answered Always ask, Allow or Never allow. Governs agents, never your own typing. More
Knowledge
A fact about a project that is briefed to agents. The opposite of a note, and the single question that decides which one something is.
Mission
An intent plus the criteria that decide whether it is finished. Completed only on evidence, and uncompleted when the evidence stops holding. More
Note
Two different things, and the page usually says which. A project note is working memory in the Brain, never briefed. A notebook note is a prompt in the global Notebook, sent only when you press the button.
Observed
Measured by J.A.R.V.I.S. from something a provider emitted, but not stated by it. A question read off a terminal is the clearest case. More
Official
Stated by the provider itself. A token count from its usage object, a rate limit it reported, an agent's own reply. More
Projection
A view computed from the session log rather than a store of its own. The Terminal, the Conversation, Analytics, Review and Search are all projections.
Project
A real folder on your disk that you have opened. A worktree is also a project, which is why it works everywhere a project works.
Provider
An agent CLI, behind an adapter — Claude Code or Codex today. What it can and cannot do is data the interface reads. More
Rail
The narrow strip of destinations down the left edge. Six, plus Settings, and it does not grow.
Retire
What happens to knowledge that stops being true: it stops being briefed and the record stays. Not deletion.
Revoke
What happens to a completed mission whose evidence stops holding. It is no longer completed, because it is no longer true.
Session
One append-only, ordered event log. Not a terminal widget, and not a chat. More
Twin
Two account cards that are the same subscription seen through two configuration directories. Detected by email, told rather than prevented. More
Unattended
The autonomy profile that assumes nobody is at the keyboard, and changes several behaviours because of it. A statement about you, not about the agent. More
Verification
What a criterion runs to decide whether it holds: Command, FileExists, FileContains, or Manual.
Withdraw
Removing a criterion from a mission, with a reason, keeping it in the record. Deleting it would let a mission be made to pass by removing the tests it failed.
Worktree
A second Git checkout of the same repository, on its own branch, in its own folder — and therefore a project. More
