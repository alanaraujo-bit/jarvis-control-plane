As palavras que este produto usa, no sentido em que este produto as usa. Várias delas são palavras comuns com um significado específico aqui, e confundir o sentido geral com o específico é como o resto da documentação deixa de fazer sentido.

Agente
Uma sessão em execução de uma CLI de provedor. Não é uma persona, não é uma configuração — é um processo.
Área
Uma das sete abas dentro de um projeto: Sessões, Arquivos, Revisão, Prévia, Worktrees, Memória, Configurações. Diferente de um destino.
Aposentar
O que acontece com conhecimento que deixa de ser verdade: ele para de ser entregue no briefing e o registro fica. Não é apagar.
Autonomia
Quanto um agente decide sozinho — Guiada, Autônoma ou Sem supervisão. A pergunta ampla. Mais
Barra lateral
A faixa estreita de destinos na borda esquerda. Seis, mais Configurações, e ela não cresce.
Briefing
O texto composto entregue a um agente antes de ele começar, fora de banda, contendo apenas conhecimento. Nunca escrito no seu repositório.
Conhecimento
Um fato sobre um projeto que é entregue aos agentes. O oposto de uma nota, e a única pergunta que decide qual dos dois algo é.
Conta
Um diretório de configuração de provedor — CLAUDE_CONFIG_DIR ou CODEX_HOME — e as credenciais que moram nele. Não é uma conta do J.A.R.V.I.S.; isso não existe. Mais
Critério
Uma condição de aceitação de uma missão, com uma verificação anexada: um comando para rodar, um arquivo para conferir, ou um julgamento que só uma pessoa consegue fazer.
Destino
Um dos seis lugares na barra lateral, mais Configurações. Diferente de uma área, que mora dentro de um projeto.
Dirigida
Uma sessão que o piloto automático está conduzindo em vez de uma pessoa. Uma sessão dirigida avisa à proteção que é dirigida, e é por isso que uma regra de perguntar recusa em vez de perguntar.
Evidência
O que uma verificação de fato produziu — um código de saída, a saída real de um comando, a presença de um arquivo, ou a confirmação de uma pessoa. Guardada, não resumida em um tique.
Gêmea
Dois cartões de conta que são a mesma assinatura vista por dois diretórios de configuração. Detectada por e-mail, avisada em vez de impedida. Mais
Memória
A memória do próprio projeto. O conhecimento nela é entregue a todo agente que começa ali; as notas nela não. Mais
Missão
Uma intenção mais os critérios que decidem se ela está terminada. Concluída só com evidência, e desconcluída quando a evidência para de se sustentar. Mais
Nota
Duas coisas diferentes, e a página normalmente diz qual. Uma nota de projeto é memória de trabalho na Memória, nunca entregue no briefing. Uma nota do bloco é um prompt no bloco de notas global, enviada só quando você aperta o botão.
Observado
Medido pelo J.A.R.V.I.S. a partir de algo que um provedor emitiu, mas não declarado por ele. Uma pergunta lida de um terminal é o caso mais claro. Mais
Oficial
Declarado pelo próprio provedor. Uma contagem de token do objeto de uso dele, um limite que ele informou, a resposta do próprio agente. Mais
Projeção
Uma visão calculada a partir do log da sessão em vez de um depósito próprio. O Terminal, a Conversa, as Métricas, a Revisão e a Busca são todos projeções.
Projeto
Uma pasta real no seu disco que você abriu. Uma worktree também é um projeto, e é por isso que ela funciona em todo lugar onde um projeto funciona.
Proteção
Uma regra sobre uma classe de operação sensível, respondida com Sempre perguntar, Permitir ou Nunca permitir. Governa agentes, nunca o que você digita. Mais
Provedor
Uma CLI de agente, atrás de um adaptador — Claude Code ou Codex hoje. O que ela consegue e não consegue fazer são dados que a interface lê. Mais
Quadro
Uma entrada no log de uma sessão: um tamanho, um número de sequência, um carimbo de tempo, um byte de tipo e uma carga. Mais
Retirar
Tirar um critério de uma missão, com um motivo, mantendo ele no registro. Apagar deixaria uma missão passar pela remoção dos testes que ela falhou.
Revogar
O que acontece com uma missão concluída cuja evidência para de se sustentar. Ela deixa de estar concluída, porque deixou de ser verdade.
Sem supervisão
O perfil de autonomia que assume que ninguém está no teclado, e muda vários comportamentos por causa disso. Uma afirmação sobre você, não sobre o agente. Mais
Sessão
Um único log de eventos, ordenado e append-only. Não é um widget de terminal, e não é um chat. Mais
Verificação
O que um critério roda para decidir se ele se sustenta: Command, FileExists, FileContains, ou Manual.
Worktree
Um segundo checkout Git do mesmo repositório, no próprio branch, na própria pasta — e portanto um projeto. Mais
