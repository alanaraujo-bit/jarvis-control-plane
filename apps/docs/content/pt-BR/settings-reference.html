Toda configuração, seu padrão, seus limites, e o que de fato acontece no momento em que você a muda. Os valores são lidos do código, não de uma captura de tela.

Duas regras que valem para todas

Sem valor é ausência de linha. Uma configuração em que você nunca encostou não tem linha nenhuma no banco, que é o que faz uma mudança de padrão chegar até você.

Os limites são aplicados no núcleo, nas duas direções. Fora da faixa na entrada é recusado, para que um valor guardado seja sempre um que alguém poderia ter escolhido. Fora da faixa na saída é limitado, para que a linha de uma versão antiga não consiga produzir um terminal inutilizável ou um orçamento zero que falha toda execução antes de começar. Um valor que não consegue ser interpretado é lido como sem valor em vez de derrubar a tela.

Limite de turnos 4 – 100 turnos 24 Uma execução mantém o orçamento com que começou. Relê-lo a cada turno deixaria uma mudança aqui mover a linha de chegada debaixo de uma execução em andamento.
Por que 4 e 100 especificamente

Abaixo de 4, uma execução sem supervisão não consegue terminar nada real e toda missão acabaria em Falhou. Acima de 100, rodar até acabar deixa de ser um orçamento — que é exatamente o que a regra contra consumir recursos indefinidamente existe para impedir. Estas são decisões de produto, não números arbitrários.

Proteções

Nove linhas, uma por operação que o núcleo informa, cada uma com Sempre perguntar · Permitir · Nunca permitir, com padrão em Sempre perguntar.

A lista é gerada a partir do que o núcleo informa, então ela consegue crescer sem que esta tela seja tocada. Veja Proteções para as nove e o que cada uma casa.

Em Sem supervisão, Sempre perguntar vira recusa

Ninguém está lá para responder. Em vez de estacionar o agente num prompt que nunca será respondido, a proteção recusa e a missão vai para Esperando com um motivo.

Celular

Estado do pareamento, um código de seis caracteres (uso único, cinco minutos, tentativas contadas), e uma declaração do que é enviado — antes de você conectar. Desconectar revoga o token, não só o pareamento local. Veja Parear o celular.

Ambiente

Somente leitura. O que foi encontrado nesta máquina — Git, Node, pnpm, Claude Code, Codex, GitHub CLI — com versões, e um botão de Reexaminar. Um provedor que não está no seu PATH não é oferecido quando você inicia uma sessão, e é aqui que você descobre por quê.

Atualizações

Sua versão atual, e uma checagem contra o endpoint de atualização. O download é verificado contra uma chave pública minisign compilada dentro do binário antes de qualquer coisa ser instalada; uma atualização que falha na verificação é recusada em vez de aplicada.

As checagens de atualização hoje informam uma falha honestamente, porque o local de release ainda não foi publicado. Veja Bloqueios conhecidos.

Configurações de projeto

A área Configurações do próprio projeto hospeda os controles de autonomia e proteções com escopo de projeto. Eles são literalmente os mesmos componentes dos globais, recebendo um id de projeto — e é por isso que os dois nunca conseguem divergir.
